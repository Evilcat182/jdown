Available placeholders
  • Write a field name in braces, e.g. {title}. The same names are used for Mandatory fields, without braces.
  • Folder templates are split at spaces, file templates and the episode folder template at dots. A part whose field is missing is left out, e.g. {title} {year_in_brackets} becomes Dune when there is no year.
  • The file extension (.mkv, …) is added automatically.
  • Values come from the folder name, then the video file name, as detected by guessit. Not every release contains every field.
